### Program 1 — Hollow Diamond Pattern

**Aim:** To print a hollow diamond pattern using stars for an odd number of rows.

**Logic:** The program prints the upper and lower halves of the diamond using spaces and stars. Only the boundary positions contain stars.

**Sample Input / Output:**

```text
Enter odd number: 5

  *
 * *
*   *
 * *
  *
```

### Program 2 — Double Triangle Pattern

**Aim:** To print a symmetric star pattern using two groups of stars separated by spaces.

**Logic:** The number of stars increases from 1 to `n` and then decreases. The spaces between the two groups are adjusted to create the symmetric pattern.

**Sample Input / Output:**

```text
Enter number: 5

*        *
**      **
***    ***
****  **
**********
****  **
***    ***
**      **
*        *
```

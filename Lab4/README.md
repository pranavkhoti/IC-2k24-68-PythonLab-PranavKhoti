## Question 2 — Matrix Operations

### Aim
To input a 3 × 3 matrix using Python lists and perform different matrix operations.

### Logic
The program takes nine elements from the user and stores them in a 3 × 3 list. Loops are used to display the matrix, calculate the total sum, main diagonal sum, largest and smallest elements, and transpose of the matrix.

### Operations Performed

1. Display the matrix in row-and-column form.
2. Calculate the sum of all elements.
3. Calculate the sum of the main diagonal elements.
4. Find the largest element.
5. Find the smallest element.
6. Display the transpose of the matrix.

### Sample Input / Output

Enter 9 elements:
1 2 3
4 5 6
7 8 9

Matrix:
1 2 3
4 5 6
7 8 9

Sum of all elements: 45
Sum of main diagonal: 15
Largest element: 9
Smallest element: 1

Transpose:
1 4 7
2 5 8
3 6 9
